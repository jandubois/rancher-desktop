S2. Both READMEs describe the identity check without its new precondition Codex GPT 5.6 Sol¶
pkg/rancher-desktop/assets/translations/README.md
| `@context` | en-us.yaml | Where in the UI the string appears |
| `@meaning` | en-us.yaml | Domain-specific meaning when English is ambiguous |
| `@no-translate` | en-us.yaml | Terms that should stay in English by default |
| `@reason` | locale files | Why a wording was chosen, or why English was kept |

`@reason` carries two meanings. It records why a wording was chosen, and it
marks a value left identical to its English source as a deliberate keep
rather than a missed translation. `validate` flags an unmarked identical
value and accepts either `@reason` or `@override`.

`merge` preserves a `@reason` across a value change and strips only
`@override`, so a note written for an earlier wording can outlive it and
still satisfy the identical-value check. Re-read the note whenever you
change the value it describes.

f5be649c0 made the check fire only when the @source snapshot is current, but the prose still promises that every unmarked identity is reported.

The same omission sits in the maintenance workflow at README.md:204-207 and in src/go/i18n-report/README.md:296-297.

## Writing source strings

en-us.yaml is the source every locale translates from, so its phrasing sets the
ceiling on translation quality.

- **Name the subject.** A subjectless passive like "Cannot be modified because
  the RD_DEBUG_ENABLED environment variable is set" gives a gendered language
  nothing to agree with, so each translator invents a referent and they disagree.
  Spanish and French were left with a bare participle agreeing with nothing.
- **Keep a sentence in one key.** `images.add` assembles one from `{action}` plus
  its `gerund`/`infinitive`/`pastTense` sub-keys, which forces English word order
  onto every language; German and Brazilian Portuguese had to rephrase around it.
- **Headings are noun phrases.** English tolerates a fragment like "From the
  blog" because the layout supplies the missing noun. Chinese, Japanese, and

troubleshooting.debugModeLockedTooltip had no Spanish or French translation at the merge base. This PR added both, already carrying a subject. The bare participles belonged to the other string the same commit reworded, preferences.locked.tooltip, whose merge-base values were Bloqueado por la política… and Verrouillé par la politique….

Review Process Notes ¶

Skill improvements

  • When a change rewrites a user-facing string that already has translations, compare the old and new values byte for byte, not as rendered text. Locale files carry typography that a diff view renders identically to its plain-ASCII counterpart: non-breaking spaces, narrow no-break spaces, directional quotes, and locale-specific punctuation. A rewrite that retypes the string silently drops them, and placeholder- and tag-based validation does not inspect whitespace. Check the surrounding file for the convention before deciding whether a difference is a regression.
  • When a change adds a skip, exemption, or early return that delegates a case to another check, verify that the named check actually runs in CI. Read the workflow files for the invocation and its flags. A comment naming another report as the owner is a claim about process, not code, and the delegated case disappears when that report is optional, manual, or gated behind a flag nothing sets.
  • When a prior round's resolution records a finding as fixed by a new test, verify the test fails without the fix. Delete or invert the code the test claims to pin and run the suite. A fixture added for a branch frequently exercises a different branch that shares its outcome, and the resolution table then records coverage the suite does not have.
  • When reviewing documentation that cites a specific code identifier, string, or symbol as evidence for a rule, check that the cited item has the history the prose claims. A rule generalized from one incident often ends up quoting a neighbouring item that was changed in the same commit, which leaves a maintainer unable to find the evidence.
