Assessment ¶

Outside the quarantined BATS workflow, the failure rate rose to 2.5% of 1,586 jobs, from 1.9% of 1,242 the week before (4-week average 2.1%). PR branches account for the rise, with 22 of their 27 failures on three Dependabot Go bumps that broke their own checks. The two gvisor-tap-vsock 0.9.0 bumps hit a compile error in the guest agent's loopback forwarder, and go-connections 0.8.2 failed the go mod tidy check; all three were merged or closed by 10-14. main had 12 failures outside the quarantine, one more than the week before, and four were the Dependabot npm scan, which has died on the @yarnpkg/core got patch every run since 2026-10-02 (upstream fix: yarnpkg/berry#7282). postinstall-body-terminated failed two mac Package jobs on main a day apart, both green on re-run; nothing retries a download whose connection drops after the HTTP status arrives, so that retry is the fix to write next. No fixed flake came back this week.

How this report is built

ci-sweep weekly --week 2026-W42 over sweep.db, one row per failed job — a run can fail on one matrix leg out of many, so the job is the unit.

  • Known flake — a job whose log matched a matchers.yaml pattern. Pattern matching only, no LLM.
  • One flake per job — when several matchers fire, the job counts under the one whose surface appears earliest in the log, because the first failure is the root and what follows is fallout: a suite killed at its wall-clock cap logs a failed wait on the way out. The others are recorded but not counted, and only a true tie is left uncounted.
  • Proven flake — the identical job passed on a re-run of the same commit, so the code cannot be at fault.
  • Unrecognized — no matcher fired. On main it earns analysis; on a PR branch it earns only a count, because PR failures are dev breakage, not CI health.
  • No log — the log expired or was never uploaded, so the sweep could not classify the failure. A data gap, not a clean bill.
  • What failed — for a known flake, the matcher's summary; otherwise the failing test and command, or the job error for a failure that never reached its tests. --fetch names the rest, at one download each.
  • Counts cover only jobs the sweep recorded. A period never swept reads as zero failures.
