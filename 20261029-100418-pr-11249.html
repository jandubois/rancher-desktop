Executive Summary ¶

This PR adds a workflow-side collector that writes a support bundle for every BATS job and lets a job that fails early upload its artifact; the fork artifacts show it working on all three platforms. The main problem is on Windows, where the bundle runs rc-status outside the PID namespace that Rancher Desktop's OpenRC uses. A probe that times out also prints nothing, and the first commit message credits the wrong change for the uploaded artifact.

Review Process Notes ¶

Skill improvements ¶

  • When a PR ports code from another project, have agents list every constant whose rationale came from the source project's environment (a timeout, a time window, a retry count, a size limit) and check it against the target's own configuration. A port copies the value and often drops the comment that tied it to the source's setup.
  • In diagnostic and collection code, check that each section separates an empty answer from a probe that failed, timed out or was skipped, and that every skip message's stated reason holds in each case that reaches it.

Repo context updates ¶

  • [repo] On WSL, Rancher Desktop's OpenRC runs in a child PID and mount namespace that network-setup creates (unshare --pid --mount-proc --fork). An OpenRC command (rc-status, rc-service) run through plain wsl.exe --distribution rancher-desktop sees the distro's root namespace and does not report the services correctly; Rancher Desktop routes such commands through the distro's /usr/local/bin/wsl-service or /usr/local/bin/wsl-exec, which nsenter init's namespaces. A process listing works from the root namespace, which sees every child process. Flag any WSL-side diagnostic or test helper that runs OpenRC commands without them.
  • [repo] On the macOS runners, a script with #!/bin/bash runs bash 3.2 even after the workflow installs Homebrew bash, and so does a shell: bash step that runs before "macOS: Install prerequisites". Under set -o nounset, bash 3.2 rejects an empty array expansion ("${arr[@]}"), so check such scripts against an empty input.
