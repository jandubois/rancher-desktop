S6. **The Kubernetes capture never logs a failing init container** — `bats/tests/helpers/kubernetes.bash:116-118` [Claude Opus 5]

## Review Process Notes

### Skill improvements

- When commits have left the branch for separate pull requests that will merge first, name those PRs in the prompt and ask agents to check every comment, test and commit body that describes code in them against the tree under review. Prose written while the fix sat on the same branch describes a state the reviewed tree no longer has, and the stacked-PR rule does not catch it because nothing in the git history links the two.
- Treat a reviewer's stated open question or unverified doubt as a finding candidate and verify it like one. Agents record doubts they could not settle outside their findings list, where consolidation does not look, and such a doubt can be the one real inaccuracy in a round.

### Repo context updates

- `[repo]` BATS per-test captures have two layouts. `capture_logs` creates the capture directory before `cp -LR "${PATH_LOGS}/" "$logdir"`, so BSD cp on macOS copies the log files flat while GNU cp on Linux and in the Windows WSL distro nests them under `logs/`. Code that writes into a capture, or a tool that reads one, must allow for both.
- `[repo]` UPDATE the `clearLoggingDirectory()` entry: it removes only regular files (`Dirent.isFile()`), so a symlink in the log directory survives an app start even when it dangles, while a regular `*.log` file that is not a logging topic does not. Separately, `rdctl reset --factory` deletes the whole log directory on macOS and Linux (`src/go/rdctl/pkg/factoryreset/delete_data_*.go`), so nothing in `$PATH_LOGS` outlives a factory reset.
- `[repo]` The BATS CI lane has a GNU `timeout` on macOS and Linux. `bats.yaml` installs coreutils on both, and Homebrew's copy is `gtimeout`. A finding that a BATS helper runs a probe unguarded for want of a timeout command applies to developer machines only.

S1. **Avoid running invalid `cp` commands when `nullglob` expands to nothing** — `collect-logs.sh:75` (suggestion, enhancement)

```bash
if [[ -d $log_dir ]]; then
    mkdir -p "$output_dir/logs"
    cp -L "$log_dir"/*.log "$output_dir/logs/" 2>/dev/null
fi
```

With `shopt -s nullglob` enabled at line 19, if there are no `*.log` files matching the glob in `$log_dir`, the glob expands to nothing. The resulting command evaluates to `cp -L "$output_dir/logs/" 2>/dev/null`, which is invalid syntax and fails (though silently because of the redirect and lack of `set -e`).

Fix: Store the glob results in an array and check if any elements exist before invoking `cp`:

```diff
 if [[ -d $log_dir ]]; then
     mkdir -p "$output_dir/logs"
-    cp -L "$log_dir"/*.log "$output_dir/logs/" 2>/dev/null
+    local files=("$log_dir"/*.log)
+    if (( ${#files[@]} > 0 )); then
+        cp -L "${files[@]}" "$output_dir/logs/" 2>/dev/null
+    fi
 fi
```

S2. **Ensure robust temporary directory prefix in `install-latest-ci.sh`** — `install-latest-ci.sh:305` (suggestion, enhancement)

```bash
    local workdir
    workdir=$(mktemp -d "$TMPDIR/rd-bats.XXXXXXXXXX")
```

If the `TMPDIR` environment variable is unset or empty, the argument to `mktemp -d` resolves to `/rd-bats.XXXXXXXXXX`, which attempts to write to the root partition and will fail on machines where the executing user lacks root/write access.

Fix: Fall back to `/tmp` if `TMPDIR` is unset or empty, or let `mktemp -d` automatically resolve the system's temporary directory:

```diff
     local workdir
-    workdir=$(mktemp -d "$TMPDIR/rd-bats.XXXXXXXXXX")
+    workdir=$(mktemp -d "${TMPDIR:-/tmp}/rd-bats.XXXXXXXXXX")
```
