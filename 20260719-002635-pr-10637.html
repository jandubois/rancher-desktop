The README blesses both and names data() capture the preferred pattern for new tables (README.md:167), so neither is a defect; DiagnosticsBody is the lone divergence from that preference. Round 2 dropped the inverse claim — move every header to computed — as a false positive, and the cited code is unchanged, so this stands as a consistency note, not a finding.
