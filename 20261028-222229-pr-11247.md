S1. **The firewall commit says it records each adapter's network category** — `1222a2855`


S2. **`Format-Table` cuts values at the transcript's width** — `.github/actions/windows-machine-info/machine-info.ps1:206-207` [Claude Opus 5.5, Gemini 3.5 Flash]


S4. **`go run` costs about a minute in every Windows job** — `.github/actions/windows-typeperf-sampler/action.yaml:59-60` [Claude Opus 5.5, Codex GPT 6 Astra, Gemini 3.5 Flash]

## Review Process Notes

### Skill improvements

- When a PR ports code from another project, check every ported comment, description and filter pattern against the destination repo's own architecture and runners, and put the facts that differ in the prompt. Prose that is true at the source passes a diff review, because nothing in the diff contradicts it.

### Repo context updates

- [repo] UPDATE: the entry saying the Windows WSL distro "is provisioned with only `curl` and `util-linux`" is stale. `bats.yaml`'s "Windows: Install prerequisites in WSL" step installs `curl netcat-openbsd openssl util-linux`.
- [repo] rancher-desktop-2 shares this repo's GitHub-hosted runners and several CI composite actions, but its Windows CI code assumes Lima, MSYS2 and the `RDD_` variable prefix. This repo runs a WSL distro under `%LOCALAPPDATA%\rancher-desktop` and uses `RD_`. When a PR ports an action or script from rancher-desktop-2, check each comment, environment filter and path against this repo's Windows backend.
- [repo] Only macOS splits a suite into one job per file (`SPLIT_PER_FILE_ON_MAC` in `.github/workflows/bats/get-tests.py`). Linux and Windows run one job per suite directory and engine, 24 each in a full run; use that count when sizing a per-job cost.
